Using Deep Learning

Overview

This tutorial walks through a practical NeuroSAM workflow in the Deep Learning widget.

Goal: use the memory attention pathway so your model sees:

  • dynamic input from current media frames,
  • static memory inputs from one labeled reference frame (memory image + memory mask),
  • outputs written to a mask feature in real time.

Prerequisites

  • A media source is loaded (video or image stack) and visible in Media Viewer.
  • You can open View -> Analysis -> Deep Learning.
  • You have a NeuroSAM-compatible weights file.
  • You have (or can create) a mask feature for output.

Step 1: Create and Label the Memory Mask

  1. Open Modules -> Data Manager.
  2. Create a Mask feature (or reuse an existing one).
  3. Go to the frame you want to use as your memory frame.
  4. Draw your reference mask on that frame.

This labeled frame is your memory-mask anchor for the memory attention module.

Step 2: Open Deep Learning and Select Device + Model

  1. Open View -> Analysis -> Deep Learning.
  2. In Device, choose:
    • GPU (CUDA) for speed, or
    • CPU if needed.
  3. In Model, select NeuroSAM.

Step 3: Load and Validate Weights

  1. In Weights, click Browse… and select your weights file.
  2. Confirm the status becomes Loaded & validated.

If status is not validated, do not run inference yet.

Step 4: Configure Dynamic Input (Media)

For dynamic image input (usually encoder_image):

  • set Source to your media key (typically media).

Dynamic inputs should come from media so each inference uses the current frame.

Step 5: Configure memory_images Static Input

For memory_images:

  1. Set Source to the same media key (usually media).
  2. Set Capture Mode to Absolute.
  3. Navigate to your memory frame.
  4. Click Capture Current Frame.
WarningKnown Capture Bug Workaround

Sometimes Absolute capture records frame 0 even when you are on a different frame.

If that happens:

  1. Move forward one frame.
  2. Move back to your memory frame.
  3. Capture again.

Step 6: Configure memory_masks Static Input

For memory_masks:

  1. Set Source to the mask feature containing your memory label.
  2. Set Capture Mode to Absolute.
  3. Navigate to the same memory frame you used for memory_images.
  4. Click Capture Current Frame.

Important: memory_images and memory_masks should be captured at the same frame.

Step 7: Configure Output Target and Batch Size

Under output settings:

  1. Set Target to either:
    • a new mask object, or
    • the same mask object that already contains your memory frame.
  2. Set Batch Size if your model supports it.

Step 8: Run Inference

Single specific frame

  1. Enter a frame number in the Frame box.
  2. Click Run Frame.

Current frame in timeline

  • Click Current to run on the frame you are currently viewing.

Frame ranges

  1. Click Run Batch.
  2. Choose either:
    • Manual range, then set start/end frames, or
    • From interval series, then choose which interval source defines your ranges.

You can use interval data to drive batch inference only over selected epochs.

What Happens After You Click Run

Inference executes on a background thread. As frames complete, predictions are written to your output mask key, and you can watch results appear in real time.

Troubleshooting

Shape mismatch error

If you get a shape mismatch error, the model was likely not exported as a compatible AOTI package for your environment.

Use the AOTI export workflow first, then retry inference:

  • How-To: Exporting an AOTI Encoder Model

Static memory capture issues

  • Ensure memory_images and memory_masks both use Absolute mode.
  • Ensure both were captured at the same memory frame.
  • If capture keeps showing frame 0, use the forward/back recapture workaround above.
